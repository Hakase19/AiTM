# Legacy asymmetric-tree results

These four 100-sample files are retained because the old asymmetric-tree pilot
showed a potentially useful AIRA advantage over its controls.

They were produced before the synchronous, topology-known collaboration
protocol was introduced. They use the removed staged/pending-receiver protocol
and must not be combined with or reported as results from the current protocol.
They are historical evidence motivating a new synchronous replication only.
